# lib/

This folder holds the MySQL Connector/J jar, which is NOT included in this repo (it is a third-party library).

1. Download https://dev.mysql.com/get/Downloads/Connector-J/mysql-connector-j-9.3.0.zip
2. Extract it and copy `mysql-connector-j-9.3.0.jar` into this folder.
3. The run commands in the README expect it at `lib/mysql-connector-j-9.3.0.jar` (run from `EcommerceStore1/EcommerceStore`).
